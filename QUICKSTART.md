# AI Problem Solver - Quick Start Guide

## Getting Started

### 1. Access the AI Problem Solver
Navigate to `/ai-problem-solver` or click "AI Solver" in the navbar.

### 2. Select Your Academic Year
Choose between:
- **1st Year**: Foundation & Basics (Focus on fundamentals)
- **2nd Year**: Intermediate Projects (Learn frameworks)
- **3rd Year**: Advanced Work (Master patterns and optimization)
- **Final Year**: Capstone Projects (Production-ready code)

Your selection affects:
- AI chat responses (tailored to your level)
- Project filtering in the gallery
- Personalized guidance

## Features Guide

### AI Chat Assistant

**How to use:**
1. Click on a quick suggestion or type your question
2. Ask about:
   - Project ideas for your year level
   - Help debugging code errors
   - Best practices for documentation
   - How to approach assignments

**Example Questions:**
- "I keep getting syntax errors in my code, how can I fix them?"
- "What are some good project ideas for a 2nd year student?"
- "How should I document my project?"
- "Can you explain what this error means?"

**How it works:**
- Responses are tailored to your academic year
- AI understands context from question keywords
- Responses include practical suggestions
- Chat history is maintained during your session

### Project Upload

**Steps:**
1. Go to "Upload Project" tab
2. Fill in project details:
   - **Title**: Give your project a clear name
   - **Category**: Select the best fit (Web, Mobile, AI, Data, Game, Other)
   - **Description**: Explain what your project does, key features, and what you learned
3. Select your project file (ZIP, PDF, DOC, etc.)
4. Click "Upload Project"

**Tips:**
- Keep file size under 50MB
- Include important files in a ZIP for better organization
- Write detailed descriptions for better visibility
- Choose accurate categories for discoverability

### View Projects

**Browse projects by:**
- Academic year (shown in your selected year)
- Category (Web, Mobile, AI, Data, Game, Other)
- Newest first (most recent uploads at top)

**Project Information Displayed:**
- Student name
- Project title and description
- Category badge
- Upload date
- File size
- Academic year

### Statistics Dashboard

**Metrics displayed:**
- **Total Students**: Number who uploaded projects
- **Total Projects**: Complete project count
- **Most Active Year**: Which year has most uploads
- **Avg Projects/Student**: Average projects per student

**Visualizations:**
- Bar chart: Projects vs Students by year
- Progress bars: Breakdown of projects and students per year

## Troubleshooting

### Chat Not Responding
- Wait a moment (response simulates network delay)
- Check if you've typed a valid question
- Try rephrasing your question

### File Upload Issues
- Ensure file is under 50MB
- Check file format is supported (.zip, .pdf, .doc, .docx, .xlsx, .csv)
- Try uploading a simpler file first

### Can't See Projects
- Make sure you've selected the correct year
- Projects may not exist for all categories
- Refresh the page if needed

### Session Lost
- Your session data is saved in browser
- Session persists across page refreshes
- Use same browser to maintain session
